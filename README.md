# Vocal Studio

Локальная студия для записи и обработки вокала, как мини-DAW: **несколько дорожек**, на каждой — своя цепочка
**плагинов** (автотюн, эквалайзер, компрессор, де-эссер, гейт, насыщение, дилей, реверберация, лимитер),
**Auto-Mix** (программа сама анализирует голос и настраивает плагины), **автоопределение тональности**.
Всё работает офлайн, на вашем компьютере.

## Запуск

* `VocalStudio.exe` — portable-версия, установка не нужна (первый запуск 5–15 секунд).
* Из исходников: `run_from_source.bat` (нужен Python 3.10+).
* Сборка exe: `build_windows.bat` → `dist\VocalStudio.exe`. Или на GitHub: Actions → *Build Windows exe* → Run workflow.

## Как работать (4 шага)

Над дорожками есть полоса **«Быстрый старт»** — она подсвечивает следующий шаг. При первом запуске появится приветствие.

1. **Добавьте звук.** Нажмите `● REC` (запись на выбранную дорожку; если дорожки нет — создастся сама) или откройте файл
   (`＋ Добавить дорожку` → «Открыть вокал из файла…» / перетащите файл в окно). Бит/инструментал — отдельной дорожкой;
   во время записи он играет в наушниках.
2. **Нажмите `✨ Auto-Mix`.** Программа определит тональность и темп, тембр, шум, динамику и резкость «с»,
   соберёт цепочку плагинов и выставит громкость относительно бита. Выберите стиль (Pop, Hard Tune, Rap, Ballad, …).
   Результат можно подправить вручную или отменить.
3. **Слушайте** — `Пробел`. Кнопка **Original (A/B)** переключает на необработанный звук для сравнения.
4. **Экспортируйте** — `Экспорт…` (WAV 16/24/32f, FLAC, OGG, MP3): весь микс одним файлом или каждая дорожка отдельно.
   `Файл → Сохранить проект` (`.vsp`) — чтобы вернуться позже.

## Дорожки

* Каждая дорожка: имя, **REC** (на неё идёт запись), **M** (mute), **S** (solo), громкость, панорама, индикатор уровня,
  кнопка **FX** (плагины). Правая кнопка по заголовку — переименовать, цвет, дублировать, очистить, удалить, Auto-Mix.
* **MASTER** — общий выход со своей цепочкой плагинов (по умолчанию Limiter).
* `Ctrl`+колесо — масштаб по времени, `Shift`+колесо — прокрутка. Клик по дорожке/линейке — переместить курсор.

## Плагины

Внизу — плагины выбранной дорожки. `＋ Добавить плагин` добавляет эффект; звук идёт сверху вниз; ▲▼ меняют порядок,
кружок включает/выключает, ✕ удаляет. Клик по плагину открывает его настройки. У каждого плагина свои **пресеты**,
а **«Готовые цепочки»** применяют набор целиком (Natural Pop, Hard Tune, Modern Rap, Airy Female Pop, Intimate,
Big Hall Ballad, Radio/Lo-Fi, Clean). Свои настройки и цепочки можно сохранять.

| Плагин | Для чего |
|---|---|
| **Auto-Tune** | исправляет фальшь: ключ/лад, Retune Speed (0 = «робот»), Humanize, Flex-Tune, Vibrato, Formant, Transpose, Detune, Amount, Ref. A; график высоты с ручной правкой нот; кнопка «🎯 Определить тональность» |
| **Noise Gate** | убирает шум в паузах |
| **Equalizer** | HPF, low shelf, 3 колокола, high shelf, LPF; узлы перетаскиваются на графике, на фоне — спектр записи |
| **Compressor** | выравнивает громкость, график gain reduction |
| **De-esser** | смягчает резкие «с» и «ш» |
| **Saturation** | тепло и плотность |
| **Delay** | эхо: синхронизация по BPM или в мс, ping-pong, фильтры |
| **Reverb** | Room / Plate / Hall / Chamber / Cathedral |
| **Limiter** | защита от перегруза |
| **Utility** | усиление, инверсия фазы, моно |

## Анализ голоса и Auto-Mix

* **Тональность** — по высоте тона вашего пения (профили Краскла–Шмуклера) и, если загружен бит, по его гармонии.
  Строй бита определяется отдельно: автотюн подстраивается под него (Ref. A).
* **Темп** подложки определяется автоматически и подставляется в Delay.
* **Тембр и динамика:** шум, диапазон голоса, «бубнёж», разборчивость, «воздух», динамический диапазон, резкость «с» →
  параметры Gate, EQ, компрессора и де-эссера.
* **Баланс:** громкость вокала выставляется относительно подложки по стилю (с запасом по перегрузу).

## Как это устроено

* Определение высоты: YIN (FFT) + Витерби по кандидатам (как pYIN). Коррекция: Retune Speed / Humanize / Flex-Tune / Vibrato
  и ресинтез **TD-PSOLA** с субсэмпловой точностью — тембр сохраняется естественно.
* Микшер (`mixer.py`) кэширует результат каждого плагина: при изменении ручки пересчитывается только то, что после неё.
* Обработка идёт после записи (офлайн), поэтому качество не зависит от задержки звуковой карты; при записи вы слышите
  бит и других дорожек (с их эффектами) + опционально себя без эффектов (`Микрофон / звук…`, нужны наушники).
