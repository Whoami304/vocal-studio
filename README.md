# Vocal Studio

Локальное приложение для записи и обработки вокала: **автотюн** (коррекция высоты тона),
эквалайзер, компрессор, де-эссер, гейт, насыщение, дилей, реверберация, лимитер.
Всё работает офлайн, на вашем компьютере. Никаких облаков и аккаунтов.

## Запуск

* `VocalStudio.exe` — portable-версия: просто запустите, установка не нужна.
  (Первый запуск занимает 5–15 секунд — файл распаковывает себя во временную папку.)
* Из исходников: `run_from_source.bat` (нужен Python 3.10+).
* Сборка exe самостоятельно: `build_windows.bat` → `dist\VocalStudio.exe`.

## Как работать

1. **Запись.** Нажмите `REC` (или `R`) — пойдёт запись с микрофона от текущей позиции. Повторное нажатие — стоп.
   Дубль автоматически сохраняется в `Документы\VocalStudio\Takes`.
   * Хотите подложку (бит) — `Load Backing…`, она будет играть во время записи. Задержку записи
     можно подстроить в `Audio Settings`.
   * `Mic Check` — включает вход микрофона, чтобы выставить уровень до записи.
   * Если позиция воспроизведения не в начале — запись заменяет дубль с этого места (punch-in).
     `Ctrl+Z` возвращает предыдущий дубль.
2. **Или откройте готовую запись**: `Open Vocal…` (wav/flac/mp3/ogg) либо перетащите файл в окно.
   Подложку можно перетащить с зажатым `Shift`.
3. **Автотюн** — вкладка `AUTO-TUNE`: выберите тональность и лад (или кликайте по клавишам, выбирая разрешённые ноты),
   настройте `Retune Speed`.
4. **Слушайте** — `Пробел`. Кнопка `Original (A/B)` включает прослушивание без обработки для сравнения.
5. **Экспорт** — `Export…` (WAV 16/24/32f, FLAC, OGG, MP3), с подложкой или без неё.

## Auto-Tune: параметры

| Параметр | Что делает |
|---|---|
| Key / Scale / клавиши | К каким нотам тянется голос. Клик по клавише включает/выключает ноту |
| Retune Speed (0–400 мс) | Скорость подтягивания. **0 = мгновенно (эффект «робот» / T-Pain)**, 15–40 = современный поп, 80+ = прозрачная подстройка |
| Humanize | Замедляет коррекцию на долгих нотах — сохраняет живое «плавание» |
| Flex-Tune | Не трогает небольшие естественные отклонения, исправляет только заметные ошибки |
| Vibrato | Глубина вибрато (100 % — как спето) |
| Transpose / Detune | Сдвиг целевых нот на полутоны / центы |
| Formant | Сдвиг формант (тембра) независимо от высоты: «ниже/выше» голос без «бурундука» |
| Amount | Общая сила эффекта |
| Ref. A | Строй (440 Гц по умолчанию) |
| Input Type / Tracking | Диапазон и чувствительность определения высоты |

**График высоты (Graph-режим).** Синяя линия — как спето, оранжевая — после коррекции, бирюзовые блоки — целевые ноты.
Блок можно **перетащить вверх/вниз**, чтобы вручную задать другую ноту; ПКМ по блоку — «не корректировать» или сброс.
Колесо — масштаб по времени, `Ctrl`+колесо — по высоте, `Shift`+колесо или средняя кнопка — прокрутка.

## Остальная цепочка

`Input → Auto-Tune → Gate → EQ → Compressor → De-esser → Saturation → Delay ‖ Reverb → Output (Backing + Limiter)`

* **EQ** — HPF, low shelf, 3 колокола, high shelf, LPF. Узлы на графике перетаскиваются, колесо над узлом меняет Q,
  ПКМ — сброс/вкл-выкл. На фоне — спектр вашей записи. Можно ставить до или после компрессора.
* **Compressor** — threshold/ratio/attack/release/knee/makeup, RMS/Peak, параллельный Mix, график gain reduction.
* **De-esser** — частота, порог, максимальное подавление; split-band или широкополосный.
* **Delay** — синхронизация по BPM или в мс, фильтры в петле обратной связи, ping-pong.
* **Reverb** — Room / Plate / Hall / Chamber / Cathedral, decay, pre-delay, size, damping, width, фильтры.
* **Пресеты** — встроенные (Natural Pop, Hard Tune, Modern Rap, …) и свои (`Save`).

## Как это устроено

* Определение высоты: YIN (FFT-версия) + Витерби по кандидатам (как pYIN) — устойчиво к октавным ошибкам.
* Коррекция: покадровая модель Retune Speed / Humanize / Flex-Tune / Vibrato; ресинтез **TD-PSOLA** с субсэмпловой
  точностью — тембр (форманты) сохраняется естественно, выравнивается громкость.
* Эффекты — собственные DSP-реализации на numpy/scipy (бикварды RBJ, лукахед-лимитер, свёрточный реверб
  с синтезируемой импульсной характеристикой).
* Обработка идёт **после записи** (офлайн), поэтому качество не зависит от задержки звуковой карты.
  Результат пересчитывается мгновенно при изменении ручек (кэшируются стадии цепочки).
  При записи вы слышите себя без эффектов (мониторинг включается в `Audio Settings`, нужны наушники).
